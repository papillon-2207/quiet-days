# 無障礙與低能量使用者驗收

目標是讓使用者無須明眼人也能自主操作，不是聲稱「加了 aria 就合格」。WCAG 2.2 AA 為基線；COGA 補充低記憶／注意力負擔策略。來源 R11–R14、R02。本文件是待執行清單，**尚未由真實 VoiceOver/TalkBack 或使用者簽核**。

## 測試組合

Safari + iOS VoiceOver、Chrome + Android TalkBack、桌面 Chrome/Firefox + NVDA、Safari + macOS VoiceOver；另測放大、高對比、鍵盤、點字顯示器及不同數位熟練度。一般自動 DOM 檢查不替代這些組合。

## 必須完成的任務

| 任務 | 驗收重點 |
|---|---|
| 建立／解鎖 | 可貼密語、密碼管理器可用、錯誤朗讀，不要求記憶拼圖 |
| 今日很疲倦 | 解鎖後第一可操作核心是快速記號，不先讀完整月曆 |
| 一個記號 | 一次啟動儲存、確認朗讀、原焦點可預期，不自動追問 |
| 不確定 | 不轉成「沒有」；不要求解釋 |
| 選症狀 | 先影響、時段；選填細節不強迫完成 |
| 自動儲存失敗 | 不丟失最新文字、可重試、錯誤不只用色彩 |
| 立即求助 | 未解鎖或存檔失敗仍可查看，不需先繳交完整表單 |
| 補昨天 | 一天一頁、回憶來源明示，不預填 PMS 歸因 |
| 修正經期開始 | 已確認出血才能設開始，允許修正，重新分析 |
| 讀模式 | 文字含資料範圍、分母、缺失、回憶與限制 |
| 匯出／刪除 | 自行選範圍、敏感欄位預設不含，完整刪除流程可操作 |
| dialog | 標題清楚、焦點受控、Escape 回復原觸發控制 |
| 320 CSS px / 放大 | 沒有重要內容被截斷、焦點不被固定區塊擋住 |
| 語音 | 不支援時文字仍可用；可中止、確認或取消轉錄 |
| 隱私 | 螢幕閱讀器與喇叭路由不由網站可靠控制；告知而非承諾不外放 |

原討論的「5–10 秒、兩個操作內」是**解鎖後最低記錄設計目標**，不是已量測結果；亦不包含開機、解鎖、輸入密語、讀完整段提示的時間。不能以降低密語保護冒充達標。web CSS px 也不同於 Android dp；本版主要快速按鈕至少 48 CSS px，高度通常 52 以上，但須依實機逐項檢查。

## 共創試用

規劃跨 2–3 個週期的知情同意試用，由全盲／低視能、先天／後天、不同讀屏熟練度參與。納入規律／不規律週期，以及有偏頭痛、GI、明顯疲倦、PMS/PMDD、PCOS、子宮內膜異位症、荷爾蒙使用或停經過渡經驗的不同人；不強迫揭露病史，更不預設所有視障女性情況相同。

安排報酬、可退出、可跳題；身體不適時不要逼迫完成測試。可用虛構資料先做任務測試。真實追蹤另行制定倫理、隱私與醫療轉介方案。

量測：無協助任務成功率、每個讀屏手勢／秒數、最不舒服日的最低標記率、補登延遲分布、誤將缺失視為無症狀的次數、語音修正、通知負擔、資訊洩露、被責備感、實際理解模式的能力。研究資料與產品使用同意分開；本版沒有上傳這些遙測。
