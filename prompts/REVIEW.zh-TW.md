# 發布前獨立審閱任務

在不修改檔案的情況下，閱讀 CLAUDE.md、docs/THREAT_MODEL.md、docs/MEDICAL_BOUNDARIES.md、docs/TEST_REPORT.md，再檢視 production source 和 tests。僅使用合成資料；不得打開真實健康備份或要求密語。

目標是找出錯誤的資料語意、可能覆寫／遺失最新內容的狀態切換、無障礙阻塞、未宣告的隱私外流、過度醫療推論，以及測試與宣稱不相符之處。每個發現附檔名／行號、正常使用情境、預期不變條件、最小修正方向、相應迴歸測試。不要把未執行的瀏覽器功能當作已證實失敗，也不要把 DOM fixture 成功當作完整 E2E。

優先審閱加密還原、CAS、編輯器 drain、背景鎖定、範圍匯出、日期／回憶來源、分析分母和週期錨點。區分 blocker、重要改善、需實機確認。測試遇到政策阻擋就記錄，不繞過。最後提供可核對的風險摘要，不生成攻擊第三方的程式，也不自動部署。
