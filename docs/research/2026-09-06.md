## 先前說法的必要修正

「信心＝完整度×重複率×一致性−其他原因」沒有明確尺度，不能直接作統計公式；本版不用它。「兩個週期」的臨床紀錄建議不等於產品可在兩次重複後確診，亦不是本版預測啟用門檻。原先的高／中／低信心文案改為可核對的資料量、缺失與粗略範圍。Android 48 dp 與 web CSS px 不同。原生通知、手錶、耳機路由判定與健康資料匯入不是純前端通用能力。Local-first 也不表示任何裝置、雲端或刪除副本都能由網站控制。

91%／77% 是特定 EMA 文獻的跨研究觀察，不是本 app 的資料；2026 CycleWise 是 protocol 而非成效結果。這些限制保存在數字台帳中，不為了延續前一答就把所有敘述寫成已驗證規格。

## 證據強度

醫療指引支持一般安全與日誌使用，不證明本產品有效。質性／人本研究支持問題與需求，不提供產品療效。Web 官方文件支持 API 語意，不取代本機整合測試。自動測試支持其實際執行的程式路徑，不代替全盲／低視能使用者、臨床或資安驗收。交付測試限制見 ../TEST_REPORT.md。
