# 威脅模型與隱私評估

## 保護目標

出血、症狀、藥物背景、自由文字、推導結果與使用偏好均按高度敏感資訊處理。核心資料不送到服務端。離線分析在解鎖記憶體計算，不另存可搜尋的明文索引。App 名稱、圖示、網址 hash、提醒與下載的預設檔名不含月經、PMS 或特定症狀。

| 情境 | 本版措施 | 仍存在的限制 |
|---|---|---|
| 鎖定裝置或旁人借手機 | 密語加密；預設背景鎖定 | 已解鎖畫面、肩窺、裝置螢幕錄影仍可看見 |
| 直接取得瀏覽器資料檔 | 加密 envelope；密鑰不落盤 | 弱密語可被離線猜測；不能靠前端延遲阻止 |
| 惡意廣告或第三方 SDK | 無廣告、分析、遠端字型與模型 | 靜態主機仍可記 IP、時間與存取路徑 |
| 同來源 XSS／惡意更新 | DOM text nodes、無 innerHTML、CSP、防嵌入 headers | 掌控主機的人仍能發送惡意新版讀取解鎖內容 |
| 惡意瀏覽器擴充／作業系統 | 不在本 MVP 防禦範圍 | 本機加密不能保護已被控制的裝置 |
| 匯出過度分享 | 分欄位、日期範圍、預覽，預設不含背景／備註 | 分享摘要本身不是加密檔；基礎日期及填寫狀態仍敏感 |
| CSV 被試算表當公式 | 危險開頭加單引號並完整引號逃逸 | 不保證每個第三方試算表匯入程式都一致處理 |
| 匯入檔案 | 大小、格式、KDF、解密與 schema 檢查成功才取代；需覆寫確認 | 密語持有人可自行修改內容，沒有醫療級 authenticity |
| 多分頁操作 | vault UUID + revision 原子 compare-and-swap | 真實 IndexedDB 瀏覽器交易本次尚待 E2E 實測 |
| 不小心刪除 | 明確核對與永久刪除確認 | 不可找回；匯出／雲端同步副本不會一起消失 |
| 語音 | 主動啟動；本機 zh-TW available 才可用；不保存錄音；預覽再加入 | 系統鍵盤聽寫、讀屏及語音供應者行為不能由本 App 全面驗證 |
| 通知在外被看到 | 沒有背景 push；ICS 只寫私人提醒 | 系統行事曆可能同步、改字、產生重複提醒 |

## 刪除的準確含義

刪除本地 vault key、記憶體引用與本 App cache；由資料即時計算的模式自然不再存在。不是硬碟安全覆寫，不會刪除下載目錄、行事曆、手機／OS／瀏覽器備份、收件人的副本或主機存取紀錄。權利聲明不能宣稱「任何地方都已刪除」。

## 鎖定與低負擔的取捨

每次解鎖都要輸入密語，確實增加疲倦時成本。故允許貼上、密碼管理員，不做 CAPTCHA 或符號規則；在明確風險說明後允許關閉離開分頁鎖定。不能為了方便就把解密密鑰放到 localStorage。WebAuthn/PRF、裝置級快速解鎖與原生 keychain 需要獨立設計、恢復策略與多瀏覽器測試，尚未實作。

## AI 開發資料隔離

只讓 Claude Code 接觸程式與虛構 fixture。`.gitignore` 排除 `.qdays`、私密 JSON、環境變數等檔，但 gitignore 不是工具讀取權限。真實日誌應放在 repo 外；不得將密語、備份、控制台中的解鎖內容、畫面截圖或個案資料貼給 AI。需要觀察錯誤時，用最小可重現的合成資料，不收集原文 telemetry。

## 發布門檻

正式招募使用者前完成真實-origin E2E、資安／加密設計外部 review、主機 headers 與日誌政策核對、回復演練、無障礙共創；機構、研究、醫療用途還需依所在地完成相應法律／倫理與臨床評估。本文件不是法律合規證明。
